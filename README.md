 App Storage

Проста десктопна программа для керування складом.

Функції
* 1. Створення своїх категорій/підкатегорій товарів
* 2. Керування кількісттю/розфасовкою
* 3. Завчасне попередження про закінчення терміну придатності товару
* 4. Можливість вивантаження даних

Як запустити програму (для користувачів Windows)
Вам не потрібно встановлювати Python чи будь-які бібліотеки. Програма повністю готова до роботи.

1. Перейдіть у розділ *[Releases]* праворуч на цій сторінці.
2. Завантажте файл `назва_програми.exe`.
3. Запустіть завантажений файл (Windows може попередити про невідомого видавця — це нормально для саморобних програм, натисніть "Докладніше" -> "Виконати в будь-якому разі").

Технології
* **Мова розробки:** Python
* **Компілятор:** PyInstaller

Для розробників (запуск із коду)
Якщо ви хочете змінити код або запустити його вручну:
1. Склонуйте репозиторій.
2. Переконайтеся, що у вас встановлено Python.
3. Запустіть команду: `AppStorage.py`
