# App Storage

Проста десктопна программа для керування складом.

## ✨ Функції
* 1. Створення своїх категорій/підкатегорій товарів
* 2. Керування кількісттю/розфасовкою
* 3. Завчасне попередження про закінчення терміну придатності товару
* 4. Можливість вивантаження даних

## 🛠 Технології
* **Мова розробки:** Python
* **Компілятор:** PyInstaller

## 🧑‍💻 Для розробників (запуск із коду)
Якщо ви хочете змінити код або запустити його вручну:
1. Склонуйте репозиторій.
2. Переконайтеся, що у вас встановлено Python.
3. Запустіть команду: `python main.py`
